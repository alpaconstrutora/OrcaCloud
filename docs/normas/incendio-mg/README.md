# Normas de incêndio — Minas Gerais (CBMMG)

Pasta dos textos que as tabelas do motor de incêndio (`utils/blueprintIncendioClassificacao.ts`
e as etapas seguintes do roadmap `docs/planos/2026-09-29-incendio-benchmark-altoqi-e-roadmap.md`)
precisam para deixar de ser **rascunho**.

Enquanto um texto não estiver aqui, a constante que depende dele fica marcada
`CONFERIR NA IT` no código, e a tela diz "Rascunho — não use para aprovação".

## Esperados

| Texto | Destrava |
|---|---|
| Decreto estadual de segurança contra incêndio e pânico (MG), com as tabelas de classificação e de exigências | E0: divisão, faixas de altura, medidas exigidas por divisão × altura × área |
| IT do CBMMG de carga de incêndio | E0: carga por divisão |
| IT de saídas de emergência | E6: população, unidades de passagem, percurso, tipo de escada |
| IT de hidrantes e mangotinhos (e a NBR 13714) | E2/E3: vazões, pressões, simultaneidade, RTI |
| IT de chuveiros automáticos (e a NBR 10897) | E5: risco, densidade, área de operação |
| IT de extintores (e a NBR 12693) | E7.1 |
| IT de sinalização (e a NBR 13434) | E7.2 |
| IT de iluminação de emergência (e a NBR 10898) | E7.3 |
| IT de detecção e alarme (e a NBR 17240) | E7.4 |

Colar o PDF (ou o trecho da tabela) aqui e avisar na sessão: a tabela transcrita perde a marca
`rascunho` e ganha a fonte com o item.
