# Arquivos

- [Portais externos (cliente, fornecedor, parceiro, investidor, corretor, síndico, colaborador)](portais-externos.md) - Como pessoas de fora da organização usam o sistema — cada portal é uma casca própria fora do Layout, identificada por token (link) ou por login com e-mail e senha que resolve o mesmo token; toda leitura passa por RPC SECURITY DEFINER (tabela direta devolve vazio pela RLS); arquivos saem por Edge Function; convites por e-mail; vocabulário visual próprio.
